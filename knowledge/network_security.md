# Network Security

## Firewalls
A firewall filters network traffic based on rules, blocking unauthorized
access while allowing legitimate traffic. Both operating systems and
routers typically include one — keep it enabled.

## VPNs
A Virtual Private Network encrypts your traffic and routes it through a
remote server, which helps on untrusted networks (public Wi-Fi) and can
hide your IP from the sites you visit. A VPN does not make you immune
to phishing or malware — it only protects the network layer.

## Safe browsing
- Prefer HTTPS sites (look for the padlock, but note HTTPS alone doesn't
  guarantee a site is legitimate — attackers use HTTPS too).
- Keep your browser and OS updated.
- Be cautious on public Wi-Fi; avoid logging into sensitive accounts
  without a VPN on untrusted networks.
- Use a reputable ad/script blocker to reduce malvertising exposure.

## Home/school network hygiene
- Change default router admin passwords.
- Keep router firmware updated.
- Use WPA2/WPA3 encryption on Wi-Fi, never open networks for anything
  sensitive.
