# Incident Response

## General priority order
1. Stop interacting with the suspicious content (don't click further, don't reply).
2. Disconnect from the network if malware/ransomware is suspected.
3. Change compromised credentials from a different, trusted device.
4. Enable MFA if it isn't already on.
5. Review recent account activity for anything unfamiliar.
6. Preserve evidence — screenshots, headers, the suspicious file/link (don't delete it, don't run it again).
7. Notify your school's IT/security administrator.
8. File a report so the incident is tracked and others can be warned if it's part of a wider campaign.

## Important limitation
An AI chatbot cannot remotely investigate or fix a compromised device.
It can only provide guidance. Treat any claim otherwise — from any tool —
with suspicion.

## Common scenarios
- **Suspicious login alert** — change the password, check active
  sessions, enable MFA, review recovery email/phone on file.
- **Lost or stolen device** — remotely lock/wipe if supported, change
  passwords for accounts that were logged in on it, notify IT.
- **Accidentally entered credentials on a fake site** — change that
  password immediately, and any other account reusing it, enable MFA,
  monitor for unusual activity.
