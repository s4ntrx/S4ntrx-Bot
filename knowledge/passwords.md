# Password Security

## What makes a strong password
- Length matters more than complexity — aim for 12+ characters, ideally 16+.
- Use a mix of upper/lowercase, numbers, and symbols, but don't sacrifice
  length to force this.
- Avoid dictionary words, names, birthdays, and predictable patterns
  ("Password123!", "Qwerty2024").
- Never reuse a password across multiple accounts — a breach on one site
  then compromises every other account using that password.

## Best practice
- Use a password manager to generate and store unique passwords per site.
- Use a passphrase (several unrelated words) for anything you must
  memorize, like your password manager's master password.
- Enable multi-factor authentication (MFA) everywhere it's offered — it
  protects you even if a password leaks.

## What CyberGuard/S4ntrx Bot never does
- It never stores, logs, or transmits the passwords you check.
- It never sends a password you're checking to the AI chat.
- Password strength checking should always run entirely in your browser.
